    Server Sync

    Your data always stays in this browser's local storage. Optionally, connect to your own server API to also keep it there as the shared source of truth — reachable from any device or browser. Every change is auto-saved to the server a moment after you make it.

    This connection has no login of its own — access is controlled entirely by your network (VPN/private network). Do not point this at a publicly reachable address.
